# GPIO、AFIO、Remap

### 基础功能、复用功能、重映射(Remap)
STM32Fxx内部集成了很多的外设控制器，比如USART、SPI、CAN等，这些外设控制器，也需要通过引脚与外设连接。复用功能就是相对于单片机的引脚而言，所谓“复用功能”，是指单片机的引脚既可以作为普通GPIO使用，也可以作为内部外设控制的引脚使用。


|名称|含义|是否需要使能AFIO时钟|
|--|---------|------|
|基础功能(Default)|GPIO 最原始、最简单的功能。你可以通过程序控制一个引脚作为 输入 或者 输出|否|
|复用功能|一个 GPIO 引脚，除了它的基础输入/输出功能外，还可以被配置为内部某个特定外设的输入/输出引脚<sup>为什么需要复用功能？芯片的引脚数量是有限的，但内部外设非常多,这也算是为了提高引脚利用率</sup>|否|
|复用重映射||需要使能AFIO时钟|

##### 复用重映射
重映射就是引脚重映射，本来每个内置外设都有原来设定的引脚，所谓的重映射就是通过某种方式，将外设本来的引脚的功能赋予给另外的引脚（比如一个外设的引脚是PA10，但你的这个引脚正在被使用，你又想用这个外设，你就可以通过重映射，将PA11设定成PA10，也就是说PA11取代了PA10的功能，成为了外设的引脚），但是重映射也是有规定可以映射到哪个引脚的（需要查看手册）而不是你想映射到哪个引脚就映射到哪个引脚。
